# Planning

Milestones and task tracking for Amaru, the new SHiP software framework.

The issues labelled `plan:milestone` and `plan:task` here, and the repository
milestones, are generated from the project plan. The organisation project
*Amaru* collects them together with the code issues in the framework
repositories. A workflow in this repository updates them every night.

Each tracking issue has a generated block between `amaru-plan:begin` and
`amaru-plan:end` markers. Don't edit inside it, because the next sync
overwrites it. Comments, and notes below the block, are kept.

## Linking your work to the plan

- Put an issue or pull request on the matching milestone in its own
  repository (for example *Technical MVP* in Trout). Repositories that
  contribute to a milestone have one of the same name.
- Or add your issue as a sub-issue of the task it implements, e.g.
  *Digitisation (1.4.3)*.

Either way, the next sync adds it to the project.

## Changing the plan

Milestones, dates and work packages are maintained in the project plan
documents (`tracking/plan.yaml` in ShipSoft/project_plan), not here. Ask the
Software Coordinator for changes.
